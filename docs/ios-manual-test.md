# iOS 수동 검증 체크리스트

## 준비

- `backend`에서 `./gradlew bootRun`으로 로컬 API를 실행합니다.
- Xcode에서 `ios/UNISTBus.xcodeproj`를 엽니다.
- `UNISTBus` scheme과 Dynamic Island를 지원하는 iPhone Simulator를 선택합니다.
- 앱 target의 bundle identifier는 `kr.ac.unist.bus`입니다.
- Simulator의 설정에서 UNIST Bus의 Live Activity가 허용되어 있는지 확인합니다.
- 백엔드 없이 fixture를 확인할 때만 launch argument `-fixture-arrivals`를 사용합니다.

## 도착 목록

- [ ] 정류장 선택 화면 없이 `40234 · 40233 · 40235`가 통합 조회 대상으로 표시됩니다.
- [ ] `513`, `713`, `743`, `753`, `1115`의 5개 노선이 도착 시각순으로 한 목록에 표시됩니다.
- [ ] 각 노선 행에 조회된 정류장 이름과 ID가 함께 표시됩니다.
- [ ] 기점·종점 응답에 같은 노선이 있어도 더 이른 도착 한 건만 표시됩니다.
- [ ] 각 행의 카운트다운이 절대 ETA를 기준으로 감소합니다.
- [ ] 새로고침과 pull-to-refresh 중 기존 목록이 불필요하게 사라지지 않습니다.
- [ ] 앱이 전경에 있는 동안 약 30초 간격으로 API 정보가 갱신됩니다.
- [ ] 정류장 한 곳만 실패하면 나머지 도착 정보와 `일부 정류장 정보 지연` 안내가 표시됩니다.
- [ ] 전체 네트워크 실패 후 재실행하면 30분 이내의 마지막 로컬 캐시가 지연 상태로 표시됩니다.
- [ ] 글자 크기를 키우거나 다크 모드로 바꿔도 노선·목적지·버튼을 읽을 수 있습니다.

## Live Activity

- [ ] 513번의 `잠금화면에서 보기`를 누르면 시작 안내가 표시됩니다.
- [ ] Simulator를 잠그면 노선과 목적지보다 큰 `남은 시간: N분 N초` 카운트다운이 표시됩니다.
- [ ] `40233 울산과학기술원(기점)`에서 시작한 713·743·753·1115번은 `출발까지`로 표시됩니다.
- [ ] `40234`와 `40235`에서 시작한 노선은 `도착까지`로 표시됩니다.
- [ ] `1분 10초 → 1분 9초 → 1분 8초`처럼 앱을 열지 않아도 잠금화면 숫자가 초 단위로 감소합니다.
- [ ] 하단에 승차 정류장과 절대 출발/도착 예정 시각이 표시됩니다.
- [ ] 정보가 stale이면 마지막 ETA 카운트다운과 함께 `마지막 정보 기준` 및 갱신 지연 경고가 표시됩니다.
- [ ] Dynamic Island의 compact, minimal, expanded 표현이 잘리지 않습니다.
- [ ] 앱을 백그라운드로 보내도 시스템 카운트다운이 계속 감소합니다.
- [ ] VoiceOver가 노선, 목적지, 승차 정류장, 상태를 텍스트로 읽습니다.

## Debug 상태 전환

- [ ] `ETA 2분 지연`을 누르면 앱과 Live Activity의 ETA가 함께 갱신됩니다.
- [ ] `데이터 지연 상태로 전환`을 누르면 카운트다운은 유지되고 `마지막 정보 기준`과 갱신 지연 경고가 표시됩니다.
- [ ] `도착 처리`를 누르면 최종 도착 상태로 종료되고 약 15분 뒤 정리됩니다.
- [ ] `추적 중단`을 누르면 Live Activity가 즉시 제거됩니다.
- [ ] 다른 버스를 선택하면 기존 Live Activity가 종료되고 새 버스 하나만 추적됩니다.

## 현재 의도된 제한

- 운영 Cloud Run의 TAGO adapter와 세 정류소 매핑은 준비되어 있지만, 로컬
  실제 호출에는 별도의 공공데이터포털 인증키가 필요합니다.
- ActivityKit 원격 등록·토큰 회전·서버 APNs 전송 코드는 포함되어 있습니다.
  최종 로컬 bundle identifier와 Push entitlement는 준비됐지만 기본 feature
  flag가 `NO`이므로 현재 unsigned/Simulator 빌드에서는 로컬 Live Activity만
  동작합니다.
- 앱이 완전히 종료된 뒤 ETA 변경이나 도착 종료를 받으려면 Apple Developer
  Team ID, APNs Key ID와 `.p8`, provisioning profile, 운영 백엔드·Scheduler
  설정이 모두 필요합니다.
- App Group과 홈 화면 위젯은 아직 포함하지 않았습니다.
