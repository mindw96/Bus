# UNIST Bus Android 친구 테스트

## 전달할 파일

`build/UNISTBus-0.2.0-live-debug.apk`

이 파일은 Android 8.0(API 26) 이상 휴대폰에 직접 설치할 수 있는 테스트 APK입니다.
앱은 아래 공개 HTTPS 백엔드에서 실시간 도착 정보를 가져옵니다.

`https://unist-bus-api-60408467370.asia-northeast3.run.app`

실제 TAGO 인증키는 APK에 포함되어 있지 않습니다.

## 설치

1. APK 파일을 휴대폰으로 내려받습니다.
2. 다운로드한 파일을 열고, Android가 요청하면 현재 사용한 브라우저 또는 파일 앱에만
   `이 출처의 앱 허용`을 잠시 켭니다.
3. `설치`를 누릅니다. Play Protect 안내가 나타날 수 있습니다.
4. 설치가 끝나면 보안을 위해 `이 출처의 앱 허용`을 다시 끕니다.

## 확인할 항목

1. 첫 화면에 `513`, `713`, `743`, `753`, `1115` 다섯 노선이 모두 보이는지 확인합니다.
2. 남은 시간이 `남은 시간: 7분 28초`처럼 한국어 단위로 매초 줄어드는지 확인합니다.
3. 한 노선의 `잠금화면에서 보기`를 누릅니다.
4. Android 13 이상에서는 알림 권한을 허용합니다.
5. 화면을 잠그고, 노선 번호·정류장·출발/도착 의미·카운트다운이 보이는지 확인합니다.
6. 알림의 `추적 중단`을 눌러 알림이 사라지는지 확인합니다.
7. 다크 모드와 큰 글씨 설정에서도 내용이 잘리지 않는지 확인합니다.

## 알려진 범위

- 인터넷 연결과 정상 배포된 Cloud Run 백엔드가 필요합니다.
- Cloud Run이 0개 인스턴스에서 시작할 때 첫 조회가 평소보다 늦을 수 있습니다.
- 이번 APK는 한 명의 신뢰할 수 있는 테스터에게 전달하는 debug 서명 파일입니다.
  정식 내부 배포부터는 별도 release 서명키를 사용합니다.
